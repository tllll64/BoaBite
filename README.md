# BioBite 快速开始指南

## 立即体验（演示模式）

### 1. 启动开发服务器
```bash
cd /Users/xiaoshizi/Documents/GitHub/BioBite
npm run dev
```

访问：http://localhost:8000/

### 2. 不需要 API Key，直接点击使用
- 首页会进入空状态，提示设置目标和规则
- 点击"去设置"进入"我的硬边界"
- 填入目标：`年底之前穿上那条收腰的裙子`
- 填入最容易多吃的时候：`加班到很晚、同事分零食`
- 点击"AI 帮我变成具体规则"（演示返回 Mock 数据，约 0.7 秒）
- 点击"保存我的承诺"

### 3. 测试冲动应对流程
- 回到首页，点击"我想吃点什么"
- 选择场景：例如"同事递来的小零食"
- 输入想法：`同事给了块蛋糕，就吃一口应该没事吧`
- 点击"说给 BioBite 听"
- 等待 AI 回应（演示模式约 0.9 秒）
- 查看 AI 的温和反馈和"吃/不吃"之外的选择

### 4. 查看食物识别（新增功能）
- 在冲动输入中提到具体食物：`蛋糕`、`薯片`、`冰淇淋` 等
- AI 会自动识别食物并估算热量和时长
- 例如：蛋糕 → 280 kcal，45 分钟消耗

## 配置真实 AI 服务（可选）

### 推荐：DeepSeek

1. **获取 API Key**
   - 访问 https://platform.deepseek.com/
   - 注册账户，创建 API Key
   - 充值 5-10 元（完全够用）

2. **在应用中配置**
   - 点击右上角设置按钮
   - 模型服务：选择 `DeepSeek`
   - API Key：填入你的 `sk-xxxxxx`
   - 点击"测试连接"
   - 点击"保存"

3. **开始使用真实 AI**
   - 回到首页
   - 重复上面的步骤，现在会调用真实的 DeepSeek API
   - AI 的回应会更加个性化和准确

### 其他服务配置

**通义千问：**
- 访问 https://dashscope.aliyuncs.com/
- 获取 API Key
- 在应用中选择"通义千问"并配置

**Kimi：**
- 访问 https://platform.moonshot.cn/
- 获取 API Key
- 在应用中选择"Kimi"并配置

## 应用架构速览

### 核心功能流程

```
首页（空状态）
  ↓
设置硬边界（目标 + 规则）
  ↓ AI 生成规则
首页（显示承诺卡）
  ↓
点击"我想吃点什么"
  ↓
输入冲动（场景 + 想法）
  ↓ AI 分析
AI 回应页面（反馈 + 选择）
  ↓
选择结果（没吃/换了方式/吃了）
  ↓
保存记录到本地存储
  ↓
首页更新（数据统计）
```

### AI 调用链路

| 功能 | 调用时机 | 返回内容 |
|------|--------|--------|
| `suggestRules()` | 点击"AI 帮我变成规则" | 3 条具体规则 |
| `respondToImpulse()` | 点击"说给 BioBite 听" | 冲动分析 + 3 个替代选择 |
| `estimateFood()` | 自动（冲动输入后） | 食物名称 + 热量 + 时长 |

## 调试技巧

### 查看本地存储数据
在浏览器开发者工具中（F12）：
```javascript
// 查看所有存储
console.log(JSON.parse(localStorage.getItem('profile')));
console.log(JSON.parse(localStorage.getItem('logs')));
console.log(JSON.parse(localStorage.getItem('settings')));

// 清空所有数据
localStorage.clear();
```

### 查看网络请求
- 打开开发者工具 → Network 标签
- 填入 API Key 后进行操作
- 观察到 DeepSeek / 通义千问 等服务的请求

### 常见问题

**Q: 模型服务超时？**
- A: 检查网络连接，或选择另一个服务商

**Q: API Key 无效？**
- A: 检查 Key 是否正确，或重新生成

**Q: 演示模式下 AI 响应很快？**
- A: 正常的，Mock 函数只是模拟延迟，真实 API 调用会稍慢一些

**Q: 数据丢失了？**
- A: 检查浏览器是否启用了 LocalStorage，或者清空了浏览器数据

## 核心 Prompt 预览

### 冲动应对 Prompt
```
你是 BioBite，一个陪伴用户戒掉"多吃一口"心态的伙伴。
用户正处在想吃多余食物的冲动时刻，并且可能正在给自己找借口。
请温和、简短、不说教地回应...
```

### 规则生成 Prompt
```
你帮助想减肥的用户把模糊的目标变成具体、可执行的硬边界规则。
每条规则采用"如果……，就……"的句式，贴合用户描述的生活场景...
```

### 食物识别 Prompt
```
用户描述了他们想吃的食物。请识别食物名称并估算热量和"蛇消耗时长"...
返回 JSON: { food, calories, duration, confidence }
```
